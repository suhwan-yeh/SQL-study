# SQL-study

날짜별 수업·복습 스크립트와 시장 데이터베이스 예제를 모았습니다. 데이터를 넣고 조회하는 기본 구문부터, 여러 테이블을 연결해 결과를 집계하는 쿼리까지 순서대로 살펴볼 수 있습니다.
